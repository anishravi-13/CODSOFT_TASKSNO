# Task 2 - Tic-Tac-Toe AI

## About the Project

This project is a simple Tic-Tac-Toe game developed using Python.

The player plays against the computer. The player uses **X** and the computer uses **O**.

The computer uses the **Minimax algorithm** to choose the best possible move.

## Features

- Human vs Computer gameplay
- Player uses X
- Computer uses O
- Minimax algorithm
- Win detection
- Draw detection
- Play again option
- Simple terminal-based interface

## Technologies Used

- Python
- Minimax Algorithm

## How to Run

1. Download or clone the repository.
2. Open the `Task2` folder.
3. Open a terminal in the folder.
4. Run:

python tic_tac_toe.py
