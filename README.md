# CODSOFT Internship Tasks

Welcome to my GitHub repository for the CodSoft Internship.

This repository contains the projects and tasks completed during my internship. Each task is organized into a separate folder with its source code and README file.

## Tasks Completed

### Task 1 - Chatbot with Rule-Based Responses

A simple rule-based chatbot developed using Python.

The chatbot responds to user messages based on predefined rules and patterns.

Technologies Used:
- Python
- Conditional Statements
- Pattern Matching
- Basic Natural Language Processing Concepts

Folder:
Task1_Chatbot

---

### Task 2 - Tic-Tac-Toe AI

A Tic-Tac-Toe game where a human player plays against an AI.

The AI uses the Minimax algorithm to select the best possible move.

Features:
- Human vs Computer
- Minimax algorithm
- Win and draw detection
- Play again option
- Terminal-based gameplay

Technologies Used:
- Python
- Minimax Algorithm
- Game Theory

Folder:
Task2

---

### Task 4 - Recommendation System

A simple movie recommendation system developed using Python.

The system recommends movies based on the movie selected by the user. It uses content-based filtering to find movies with similar descriptions.

Techniques Used:
- Content-Based Filtering
- TF-IDF
- Cosine Similarity

Technologies Used:
- Python
- Pandas
- Scikit-learn

Folder:
Task4_Recommendation_System
